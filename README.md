草刈り活動記録 Ver.3.0 — 助成金画面 OCR追加

管理者画面 > 🧾助成金 > 領収書・購入明細を登録 から、画像またはPDFを選び「選択した領収書をOCR」を押してください。PDFはページ番号を指定できます。
OCR結果の文字を編集し「候補を入力欄に反映」を押すと、品名・購入日・税込金額・購入先の候補をフォームに反映します。自動保存はしません。原本と照合し、必要なら修正したうえで「領収書と経費を保存」を押してください。

Tesseract.js 5.1.1（日本語＋英語）とPDF.js 4.10.38をCDNからオンデマンドで読み込みます。初回OCR時にはインターネット接続が必要です。OCR処理自体はブラウザ内で行います。CDNを利用するため外部スクリプトの読み込みは発生します。認識精度は領収書の画質・形式に依存します。

Firebase Realtime Databaseルールは変更していません。最新版のkusakari匿名認証ルールを前提としています。Firebase Storageのアクセス権は別管理で、領収書アップロードが失敗する場合はStorageルールを確認してください。匿名認証は本番の個人情報・決済情報を扱う用途には適しません。

Ver.2.9からその他の画面・保存方式は維持しています。Firebaseへの自動デプロイは行っていません。ブラウザ実機でのOCR読み取り・Firebase保存の動作確認は未実施です。
