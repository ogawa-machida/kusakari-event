# 小川自治会 草刈り活動記録 Ver.1.4（簡易ログイン試験版）
URLを開き共通PIN「1234」を入力。Firebase Authenticationの匿名認証で複数端末から共有します。

## 設定
1. Firebase Console > Authentication > Sign-in method で「匿名」を有効にする。
2. Realtime Database Rules を `firebase-database-rules-merged.json` に更新する（既存の他領域のルールを保持した統合版）。**事前に現行ルールと比較し、バックアップしてください**。
3. Storage Rules は既存ルールを消さず、`firebase-storage-rules-example.txt` の match ブロックを既存の service/firebase.storage/match 内に追記する。
4. index.html をHTTPSで公開し、スマホから開く。ローカル file:// では動作しないことがあります。
5. 2台で入力・同期・写真登録を検証する。

## セキュリティ上の重要な制限
- PINはHTMLに埋め込まれており、誰でもコードから確認できます。Firebase側はPINを検証しません。
- 匿名認証を有効化したFirebase利用者は、PINを経由せず `kusakari` にアクセスできる可能性があります。**実運用の個人情報・顔写真には使わないでください**。
- 試験中は架空の活動記録や人物が写らないテスト画像を使ってください。
- この版の利用者識別は匿名UIDです。誰が登録したかを確実に特定できません。
- 仕様確定後、サーバー側認証、利用者権限、Storageアクセス制限、監査ログに置き換えてください。
- 既存の会計・避難所・会館管理アプリのルールは変更していません（ただしFirebaseプロジェクト全体の設定に影響しないことを確認してください）。

## Ver.1.5 チェックリスト自動判定
- ホーム画面のチェックリストは読み取り専用。手動チェックを廃止。
- 写真、活動記録、機材使用記録がFirebaseに保存されると自動で再判定され、他端末にも同期。
- 安全講習と反省会は、該当写真と活動記録の両方が必要。
- 刈払機・芝生バリカン・C-13/C-14は、該当機材の「使用」保存と機材番号を紐付けた機材使用写真の両方が必要。
- C-13/C-14は現在購入予定のため、未購入の間は進捗分母から除外。購入済みへの変更は今後の機材台帳実装時に対応。
- 既存の `kusakari/events/.../checks` データは参照しません。削除もせず保持します。
- チェックは登録内容の存在を示すだけで、作業実施・写真の適切さを保証しません。提出前に確認してください。


## Ver.1.6 スマホインストール（PWA）
- `index.html` と `manifest.webmanifest`、`sw.js`、`icon-192.png`、`icon-512.png` を**同じ公開ディレクトリ**にアップロードしてください。HTMLだけではアイコンが反映されません。
- アイコンは画像の外周の黒い余白を補完した正方形のフルブリード版です。白枠は画像に含まれません。ただしOSのアイコンマスク・余白は端末に依存します。
- Android Chrome: 「アプリをインストール」ボタン（対応環境で表示）、またはメニューからホーム画面に追加。
- iPhone Safari: 共有→ホーム画面に追加。
- HTTPSが必要です。GitHub Pagesは対応しています。Firebase SDKはCDNから読み込むため、オフラインで活動記録を保存することはできません。
- 以前のバージョンがホーム画面にある場合は一度削除し、Chrome/Safariのページを再読込して追加し直してください。
- Firebaseのデータ構造・ルールは変更していません。
